# Cryoaerosolization paper data and Attention U-Net resources

This repository contains figure files, available source data, analysis scripts, and machine-learning resources associated with the manuscript:

**Cryoaerosolization Enables Scalable Vitrification-Based Cell Cryopreservation**

Joseph R. Kangas, Abhilash Ojha, Minhan Jiang, Mohammad Shameem, Bhairab N. Singh, John C. Bischof, and Christopher J. Hogan Jr.

## Repository contents

- `Figure_1` through `Figure_9` contain files associated with the main-text figures. Depending on the figure, these include MATLAB scripts, numerical source data, model outputs, and final figure images.
- `SI_Figure_1` through `SI_Figure_4` contain files associated with the Supplementary Information figures.
- `UNET_ML_code/Training_Dataset` contains the microscopy tiles and segmentation masks used for model development.
- `UNET_ML_code/Trained_Model` contains the trained Attention U-Net model.

Some manuscript figures combine experimental images, schematics, and numerical panels. Consequently, not every final composite figure is generated by a single script. Numerical source files and analysis scripts are provided where applicable.

## Main-figure analysis

MATLAB was used for statistical analysis, physical modeling, and generation of the numerical panels. Scripts should be run from their corresponding figure directory so that relative file references resolve correctly.

The main-figure folders include analyses of:

- cooling rate and throughput
- critical-cooling-rate inversion
- aerosolization stresses and droplet relaxation
- intracellular cryoprotectant transport
- cell viability and recovery
- droplet warming simulations

The manuscript analyses were performed using MATLAB R2025a. COMSOL Multiphysics 6.1 was used for the finite-element warming simulations associated with Figure 9.

### Statistical source files

Where statistical comparisons are shown, the associated summary and statistical tables are included with the figure files. Figure 8 additionally contains a processed field-level table, independent-experiment means, and a worksheet-cell mapping documenting the assignment of each measurement used in the analysis. The original Figure 8 workbook is retained unchanged.

## Attention U-Net resources

The trained network is a multi-output Attention U-Net developed for droplet segmentation under the microscopy conditions used in this study. Its two output heads predict droplet centroids and droplet perimeters. These outputs were combined to separate overlapping droplets and estimate droplet diameters.

The available files are:

```text
UNET_ML_code/
├── Trained_Model/
│   └── AttentionUNET_Multichannel.keras
└── Training_Dataset/
    ├── X_train_600_896x896.npy
    ├── Y_train_centroid_600_896x896.npy
    └── Y_train_perimeter_600_896x896.npy
```

The dataset contains 600 image tiles resized to 896 × 896 pixels. The tiles were divided into an 80% training set and a 20% validation set after tiling. Tiles originating from the same microscopy frame were not explicitly prevented from appearing in both subsets. No separate independent test set is included.

The model was developed for the controlled imaging conditions used in this study and is not presented as a general-purpose segmentation model for unrelated imaging systems.

## Large files

The trained model and NumPy arrays are managed with Git Large File Storage. After cloning the repository, install Git LFS and retrieve the large files:

```bash
git lfs install
git lfs pull
```

## Reproducing a numerical figure panel

1. Open the relevant figure directory.
2. Confirm that the data files referenced by the script are present.
3. Run the relevant analysis script from that directory.
4. Compare the generated numerical panel with the corresponding manuscript figure.

The required software depends on the figure. MATLAB scripts may require functions or toolboxes used in the original analysis. Machine-learning files require a TensorFlow/Keras environment compatible with the saved model.
